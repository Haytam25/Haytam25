## 🚀 Featured Engineering Projects

### 🔍 [NetScanner](https://github.com/Haytam25/NetScanner)
A modular, lightweight CLI network reconnaissance tool written in Python. It combines Network-layer host verification (ICMP) with Transport-layer service auditing (TCP port mapping and passive banner grabbing) to safely map network perimeters.

### 🛡️ [LinuxHardener](https://github.com/Haytam25/LinuxHardener)
An automated Shell script compliance engine that audits local Linux server nodes against foundational security baselines. Automatically evaluates SSH server security configurations, network firewall states (`ufw`/`firewalld`), and critical file system permissions.

### 🔒 [Password Checker & Manager](https://github.com/Haytam25/password-checker-csharp)
A console-based security application built in C# demonstrating secure credential handling, salted cryptographic storage, and defensive user-input masking.
